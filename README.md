# جزيرة المرح · Fun Island

موقع تعريفي وتفاعلي لمؤسسة ملاهي جزيرة المرح الاقتصادية. الهوية الحالية مستوحاة من جزيرة وشاطئ ونخيل وأمواج، بألوان الرمل والأصفر والأخضر والبرتقالي ولمسات مائية. العربية والإنجليزية صفحات مستقلة، مع وضع ليلي ونهاري محفوظ في المتصفح. معلومات المؤسسة مجمعة ضمن الأعمال والشركات، والرحلات لها صفحة مستقلة.

## التشغيل

يتطلب Node.js 24 وnpm.

```bash
npm ci
npm run dev
```

الموقع: `http://127.0.0.1:4321/funland/ar/`، والإنجليزية `/funland/en/`.

```bash
npm run check
npm run build
npm test
npm run preview
```

في Windows يفضل تشغيل المشروع من قرص محلي، لأن تثبيت node_modules داخل قرص Google Drive الافتراضي قد يفشل. ملفات المصدر قابلة للمزامنة بشكل طبيعي.

## الصفحات والوظائف

- الرئيسية، التجارب، الأعمال والشركات (بما فيها تعريف المؤسسة وبياناتها)، الرحلات والمجموعات، خطط لزيارتك، الأسعار والعروض، الخصوصية، وصفحة 404. روابط «عن المؤسسة» القديمة تحول إلى الأعمال وبيانات التسجيل.
- خريطة تصورية تفاعلية، تصفية أنواع التجارب، ونوافذ تفاصيل قابلة للاستخدام بلوحة المفاتيح.
- تبديل اللغة يحافظ على الصفحة الحالية؛ RTL/LTR مع روابط canonical وhreflang وخريطة XML.
- حفظ المظهر فقط في localStorage، ودعم تفضيل تقليل الحركة.
- ملف المؤسسة قابل للطباعة من صفحة «الأعمال والشركات».
- صفحة الرحلات تشمل خطوات التنسيق، تفاصيل تحتاج لاتفاق، وأسئلة منظمي الرحلات. نموذجها يجهّز ملخص طلب محليًا يمكن نسخه ولا يرسل بيانات أو ينشئ حجزًا. يتأكد من التاريخ والأعداد، ولا يطلب بيانات الأطفال. يلزم ربط قناة اتصال معتمدة وخلفية خادمية لتلقي طلبات فعلية لاحقًا.
- حالة الافتتاح تراعي توقيت الرياض والفترات العابرة لمنتصف الليل والإغلاقات الاستثنائية؛ لا تعرض حالة إيجابية عند غياب الأوقات المعتمدة.
- أحداث `funisland:analytics` محلية لا ترسل بيانات إلى مزود خارجي. يلزم اعتماد مزود وسياسة الخصوصية قبل توصيل التحليلات.

## المحتوى

المصدر المركزي هو `src/data/site.json`. بيانات السجل مأخوذة من الصورة المقدمة من المالك: السجل `4030425656` والرقم الموحد `7025421574`. لم يتم التحقق المستقل من الحالة الحالية. الاسم الإنجليزي ترجمة وصفية وليس اسمًا قانونيًا إنجليزيًا معتمدًا.

الأسعار والأوقات والعنوان الدقيق ووسائل الاتصال التشغيلية غير معتمدة حتى الآن، ولذلك لا يعرض الموقع أسعارًا أو عبارة «مفتوح الآن» أو رابط اتجاهات افتراضي. الهاتف الموجود في المستند محفوظ كمصدر لكنه غير مفعل للتواصل. التصنيفات الحالية للألعاب مستمدة من التصور، وليست قائمة جرد معتمدة.

قبل الإطلاق التجاري: اعتماد الشعار النهائي، الصور الحقيقية، أسماء الألعاب وشروط العمر والطول، العنوان والاتجاهات، ساعات العمل، الأسعار والعروض، البريد والهاتف وواتساب، وسياسات الزيارة. لا توجد خدمة حجز أو دفع أو رصيد عميل متصلة بهذا الإصدار.

صورة `public/images/island-beach.webp` رسم هوية مولّد للشاطئ والنخيل والألعاب وليست تصويرًا للموقع الحقيقي. صور الألعاب المرخصة تعبيرية أيضًا. المصادر والتراخيص ووصف التوليد في `docs/assets.md`. لم تعد صورة الجزيرة الزرقاء القديمة مستخدمة في الصفحات.

### الأوقات

`hours` يربط رقم يوم الأسبوع (0 الأحد إلى 6 السبت) بقائمة فترات بصيغة 24 ساعة. مثال:

```json
{"3": [["16:00", "02:00"]], "4": [["16:00", "23:00"]]}
```

`exceptions` يربط التاريخ المحلي بفترات بديلة. `{"2026-09-23": []}` يعني إغلاق اليوم كاملاً، بما فيه امتداد فترة اليوم السابق. الأوقات المتساوية لا تعني 24 ساعة. لا تستخدم فترات غير مكتملة.

### إدارة المحتوى

صفحة `/funland/admin/` توفر رابطًا مباشرًا لمحرر GitHub يتطلب صلاحية كتابة. الحفظ في GitHub يعيد بناء الموقع. إعداد Decap CMS موجود في `/admin/config.json` ويتيح تحرير بيانات المؤسسة والألعاب والفروع والباقات والعروض والأسئلة الشائعة والصور.

لإظهار محرر Decap المرئي، اربط خدمة GitHub OAuth متوافقة مع Decap، ثم عيّن عنوانها HTTPS في متغير المستودع `PUBLIC_CMS_AUTH_URL`. أعد تشغيل النشر. سر OAuth يبقى على خادم المصادقة، ولا يوضع في أي متغير PUBLIC أو ملفات المشروع. [توثيق المصادقة الرسمي](https://decapcms.org/docs/github-backend/).

المصادقة الخارجية غير مهيأة حاليًا. صلاحيات Decap تعتمد على صلاحيات GitHub، وليست نظام أدوار مستقلًا للتسويق والتشغيل وخدمة العملاء. الأدوار الدقيقة والحجوزات ولوحة التشغيل الكاملة تحتاج خلفية خادمية مستقلة في مرحلة لاحقة.

العروض المنشورة فقط تظهر ضمن المدى `start` و`end` (YYYY-MM-DD بتوقيت الرياض). يعاد بناء الموقع يوميًا عبر GitHub Actions لتحديث العروض؛ التغيير ليس لحظيًا، وقد تتأخر مهام الجدولة لدى GitHub. لا تستخدم هذه الآلية لتسعير لحظي أو مخزون.

## GitHub Pages

المستودع المستهدف: https://github.com/nasseh2005-byte/funland

ملف `.github/workflows/deploy.yml` يبني ويفحص الموقع ثم ينشر `dist` إلى GitHub Pages. من إعدادات المستودع: **Settings → Pages → Source: GitHub Actions**. قد تحتاج إلى تفعيل Pages أول مرة بصلاحية مالك المستودع.

العنوان المتوقع بعد نجاح النشر: https://nasseh2005-byte.github.io/funland/

هذا عنوان مستهدف؛ وجوده في الوثائق لا يعني أن النشر تم. افحص نتيجة GitHub Actions.

لاستخدام نطاق مستقل غيّر `SITE_URL` و`BASE_PATH` في إعدادات البناء. مثال: `SITE_URL=https://example.com` و`BASE_PATH=/`، واضبط النطاق لدى الاستضافة. تتعامل روابط الموقع والأصول مع المسار الأساسي.

## البنية

`src/layouts` للإطار العام، `src/components` للأقسام، `src/pages` للصفحات والبيانات العامة، `src/styles` للتصميم، `src/scripts` للتفاعل، `src/lib/hours.mjs` لحالة الافتتاح، و`tests` للتحقق من الروابط والأصول والترجمة والأوقات وإعدادات CMS. الموقع يخرج HTML ثابتًا ولا يتطلب خادم تطبيقات للتصفح.
